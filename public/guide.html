Return to Attendance Desk

Browser attendance guide

No application installation is required. Open this website over HTTPS and prepare the same browser before entering a dead zone.

Students

  1. Choose I am a Student, prepare offline resources while connected, and bookmark the exact #/student link. Test reopening that link without connectivity. A home-screen icon may still open role selection.
  2. Confirm your official student ID and enter the current room challenge.
  3. Display the QR and wait for the teacher to confirm it was saved.
  4. Ask for manual check-in if your device, display or cached website is unavailable.

Teachers

  1. Choose I am a Teacher. Create or unlock your PIN. Start with Import master list (CSV or Excel). Match columns, choose a worksheet if needed, and complete blank course, section, term, student ID and name fields in the preview. Apply shared details only to blanks. Resolve conflicts, then confirm saving classes and enrollment together. Optional fields may stay blank; omitted enrollment is retained. Add class manually remains available.
  2. Choose Start attendance in the class. Review start time, report timezone, grace and the generated room challenge.
  3. Verify each student presenting a pass. Start the camera or use Manual check-in / correction (F2).
  4. For disputed duplicates, flag the review, verify identity and enter a resolution. Correct attendance separately if needed.
  5. Choose Review attendance to pause the camera, resolve disputes, review unrecorded students and close the session to reconcile absences.
  6. Download Excel/CSV and an encrypted backup. Check that browser downloads actually saved the files.

Reopening and recovery

Closed sessions are read-only. Reopen with a reason to make changes. Automatic closure absences return to unrecorded; explicit teacher decisions remain.

Lock teacher records to restore an encrypted backup. Restoration replaces all current local records after validation. Keep a separate backup and the PIN. Forgotten secrets cannot be reset to decrypt old records.

Existing records and class defaults

Legacy sessions remain in Unassigned records until you explicitly associate them with matching classes. Review section students before copying enrollment. Class Defaults affect future sessions only. Use Backup & storage for v2 archives containing class/enrollment data; old v1 archives remain supported.

Limits

QR rotation and room challenges do not prove identity. Browser persistence can be denied and does not replace backups. Wake lock is optional and does not control brightness. Never clear website data as a routine troubleshooting step.
